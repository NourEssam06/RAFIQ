# PRD reconciliation and architecture rubric

The deterministic spine lint passed with zero findings. The eight decisions cover the product capabilities, service boundaries, stack, deployment environments and operational gates. The draft needs four clarifications where two teams could implement different behavior.

| Priority | Decision | Finding and disposition |
|---|---|---|
| High | AD-7 | The browser owns current observation, while the API executes sends. A cached eligible state can outlive offline cancellation or camera loss. Bind each attempt, including the second contact, to a fresh, single-use browser authorization for the active sequence and current qualification. Fail closed on lost contact or uncertain freshness. Define the send/cancel ordering and verify a partition between eligibility and dispatch. PRD AC-09–10 and §8.5. |
| High | AD-5/6 | Separate datasets alone do not protect small groups. Give the R result publication path ownership of distinct-participant thresholds and complementary suppression before results reach UI, export or reporting. Require the MCP adapter to allowlist fields from §8.8 for every response. A valid owner and scope alone permit more fields than this client may receive. PRD FR-17, FR-20 and §§8.7–8.8. |
| Medium | AD-1/3/5 | The browser, replay and benchmark need one versioned behavior-policy and observation contract. Bind class observability and explicit user pause versus camera loss, trace timestamps and overlap grouping to a shared version. Keep the original policy and source traces available to eligible replay jobs. Without this agreement a correct R implementation can still calculate the wrong denominator or count the same incident twice. PRD AC-11, FR-14/16/18 and §8.3. |
| Medium | AD-8 | A zero-charge host and encryption do not define what operational logs may retain. Carry the accepted privacy-filtered logging rule from the run decision record into the spine. Specify a diagnostic field allowlist and redact sensitive media, precise location, contact details and bearer credentials before emitting logs. PRD NFR-05 and the approved Q17/Q18 decision. |

This is a greenfield initiative without an inherited architecture spine. The named technologies match the recorded choices. Provider eligibility, exact builds, capacity, model qualification and restore evidence are explicit activation gates. The TRD link is an outstanding assembly check until the companion file is written.
