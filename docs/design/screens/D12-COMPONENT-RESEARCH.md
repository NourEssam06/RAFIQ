## License, implementation and accessibility

- **Animate UI.** The public repository’s controlling `LICENSE.md` specifies **MIT with a Commons Clause condition**. It permits free use in a product and restricts selling or redistributing the original components themselves. Retain the copyright and permission notices. Install the React package, Motion and one matching underlying primitive only if adopted. The demos use utility styling and additional imports in places. Use existing RAFIQ icons, styles and tokens. The documented integrations fit the Next.js/TypeScript architecture as client-side controls, subject to peer/lockfile qualification. No bundle size or performance measurement was run. [Repository license](https://github.com/imskyleen/animate-ui/blob/main/LICENSE.md) · [Source repository](https://github.com/imskyleen/animate-ui) · [Package and peers](https://animate-ui.com/docs/react) · [Keyboard and reduced-motion behavior](https://animate-ui.com/docs/accessibility) · [RAFIQ architecture](../../TRD.md#11-runtime-and-dependency-baseline)
- **Press and stepper.** Give both controls independent labels and a single score state. Keep exact changes immediate and leave the caret in place. A short color transition on an existing pressed state can use CSS without a JavaScript dependency. For optional step buttons, respect a qualified increment, disable an unavailable direction, and retain the typed alternative. [Motion license](https://github.com/motiondivision/motion/blob/main/LICENSE.md) · [Motion reduced-motion hook](https://motion.dev/docs/react-use-reduced-motion) · [CodePen public Pen licensing](https://blog.codepen.io/documentation/licensing/) · [Spinbutton guidance](https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/)
- **Reveals and processing.** Keep scope, required provenance and status copy stable during layout effects. Any spinner is supplemental, indeterminate and limited to one visible submission indicator. Browser verification should cover reduced motion, visible focus, error association, assistive-technology announcements and source paging. Minimize client work while dragging. A custom picker adds focus/portal and touch testing. A disclosure with animated height changes layout. [Combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) · [Slider pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider/)
- **Pen fidelity.** Draw editable states for the slider at rest, focus and pressed, and the exact field at valid and invalid input. Draw closed/open disclosures and selectors with focused and selected rows, and still queued, processing, ready and retry states. Use short start/end annotations for effects if selected. Pen can convey these endpoints and hierarchy. Browser code supplies drag/key synchronization, focus, validation, portals, status announcements, motion preference and real job transitions.

## Approved selections

The user selected **D12-C01, C04, C07, C10 and C13** for layout A. The slider adds quick exploration, the paired field preserves exact entry, and a 150 ms thumb-fill transition marks the pointer press. The selector, evidence and job feedback use immediate state changes. The full-width saved history follows the form. The explored side-by-side layout would keep recent runs visible during editing and has less room for long dates and statuses at intermediate widths.

Motion’s **AnimateNumber** is a paid Motion+ feature, and Magic UI’s **Number Ticker** displays an animated number instead of handling exact form entry. Neither is shortlisted for the threshold field. [Motion AnimateNumber](https://motion.dev/docs/react-animate-number) · [Magic UI Number Ticker](https://magicui.design/docs/components/number-ticker)
