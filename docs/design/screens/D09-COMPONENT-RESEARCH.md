The standard or custom RAFIQ set is **C02, C03, C06, C08, C11 and C13**. It preserves the established controls and exposes all denominators without an added dependency. **C04** or **C05** can supply the selector accent if approved. For a shared chart renderer, **C01 and C12** are a matched pair. **C14** adds calendar browsing where paired fields alone are inconvenient. A fully static version uses the same scope, controls and analysis with immediate visual state changes.

## Adaptation checks

- **Charts.** The chart library can offer built-in keyboard support, but RAFIQ still needs a stable exact-value table, scoped narration and the monitored exposure and coverage readout. Verify line gaps, metric-specific units, touch selection and same-value inspection. Prefer a single renderer if both line and bars use a library. Verify interaction cost on the reference laptop, especially across all available history. [shadcn Chart accessibility and usage](https://ui.shadcn.com/docs/components/base/chart)
- **Heat shading.** Preserve visible incident counts and jointly observable session counts. Distinguish zero, no joint observation and the diagonal by text and pattern. Use a labeled fixed scale for the visible matrix. Keep version and eligibility explanations text-accessible. [Two-header table semantics](https://www.w3.org/WAI/tutorials/tables/two-headers/)
- **Date controls.** Keep inclusive endpoints, displayed IANA zone and explicit Apply in the surrounding form. Verify typed dates, keyboard travel, focus return, localized input and month layout. Carry the dates using the approved calendar contract. [DayPicker range selection](https://daypicker.dev/selections/selection-modes) · [DayPicker time zone](https://daypicker.dev/localization/setting-time-zone)
- **Motion.** Pen shows selected, focused and settled states. Keep native focus and data exposure immediate. For a library treatment, test rapid changes, a disabled animation preference and cancellation of a superseded visual transition. [Motion reduced-motion hook](https://motion.dev/docs/react-use-reduced-motion)

Aceternity’s Compare preview was reviewed for comparison and excluded because its image-reveal drag interaction cannot expose aligned evidence for two to four sessions. Animate UI’s Tabs was reviewed for selector motion. Its documented sequential blur and panel transitions, including a reduced-motion fade sequence, do not match the immediate analytical state change. Its repository license also adds a Commons Clause to MIT. These are outside the candidate set.
