# D17 Reports — free component research

**Sources inspected 25 November 2026.** These references cover the report list, generation status, initial loading, first-use guidance, and row actions. The Pen implementation uses the static RAFIQ baseline. The research identifies optional motion components the driver can understand with motion disabled. [D17 design and Pen handoff](D17-SHAPE.md)

## Selection by need

- **Document list.** Reuse D06 rows with a static job-to-ready update. If optional motion is selected, prefer a short RAFIQ accent. D17-C01 is the closer structural reference because the rows can retain stable identity and content. D17-C02 demonstrates a new-entry cue but its showcased queue is unsuitable for actual report records. [Magic UI registry source](https://magicui.design/r/animated-list.json) · [Motion reduced-motion guidance](https://motion.dev/docs/react-accessibility)
- **Processing.** Use D05’s icon and persistent **Processing** label. For an animated option, D17-C03 is the smaller adaptation if utility CSS already exists. Fit it into the incumbent icon slot, draw the same-size static fallback and avoid running an animation across a long list of jobs. D17-C04 is useful if the workspace already uses Motion. Keep **Queued** and all terminal states still. [Animata manual source](https://animata.design/docs/progress/spinner) · [Motion example](https://motion.dev/examples/react-loading-circle-spinner)
- **Initial loading.** Use D06’s still row skeleton. D17-C05 is the closer visual reference because its repeated rows align to a list. D17-C06 supplies stacked shapes. Both manual snippets supply static placeholder geometry. D17-C11 shows a one-time opacity option if a loading accent is selected. Keep it off on repeated reads, when only affected rows or status need to update. [List skeleton source](https://www.animata.design/docs/skeleton/list) · [Report skeleton source](https://animata.design/docs/skeleton/report) · [Fade source example](https://animate-ui.com/docs/primitives/animate-ui/fade)
- **Empty state.** Use D06’s inline feedback pattern with a short external authoring workflow and **Open Connections**. Use a native disclosure for optional help in the populated view. D17-C08 is the closer motion candidate if progressive disclosure needs a transition. D17-C07 is a one-time transition reference when successful retrieval changes a previously empty region. In a disconnected or unknown grant state, the empty screen still provides the generic setup path. [Collapsible demo and examples](https://animate-ui.com/docs/primitives/radix-ui/collapsible) · [AnimatePresence demo and examples](https://motion.dev/examples/react-animate-presence-modes)
- **Contextual actions.** Use the direct **Review report** link and inline correction or setup guidance where appropriate. No overflow menu is required by the current action inventory. If additional actions are later approved, D17-C09 or D17-C10 matches the corresponding existing primitive stack. Avoid adding a second stack for a row menu. [Radix menu docs](https://animate-ui.com/docs/primitives/radix-ui/dropdown-menu) · [React Aria menu docs](https://animate-ui.com/docs/primitives/react-aria/dropdown-menu) · [Animate UI accessibility](https://animate-ui.com/docs/accessibility)

## Compatibility, license and Pen representation

- RAFIQ’s approved baseline pins Next.js, React and TypeScript. Tailwind utility assumptions, helper paths, peer versions and bundle impact require verification in the actual frontend before adopting a snippet or dependency. The package-backed candidates require an appropriate client boundary. The Animata skeletons can be rendered as light markup and CSS. Restrict animation to the status cue, help disclosure, or brief accent to avoid repeated work in the list. [RAFIQ stack](../../TRD.md#1-system-and-technology-stack) · [Animata setup](https://www.animata.design/docs/setup)
- Magic UI, Motion and Animata publish MIT licenses. Preserve copyright and permission notices when copying covered software. Animate UI publishes MIT with a Commons Clause that permits use in products and restricts sale or redistribution of the original components themselves. Preserve the copyright and permission notices. [Magic UI license](https://github.com/magicuidesign/magicui/blob/main/LICENSE.md) · [Motion license](https://github.com/motiondivision/motion/blob/main/LICENSE.md) · [Animata license](https://github.com/codse/animata/blob/main/LICENSE.md) · [Animate UI source](https://github.com/imskyleen/animate-ui) · [Animate UI license](https://github.com/imskyleen/animate-ui/blob/main/LICENSE.md)
- Pen can represent document rows and ready-state accent endpoints for D17-C01/C02, rest and implied motion poses for D17-C03/C04, static skeleton shapes for D17-C05/C06, empty, filled or help-expanded frames for D17-C07/C08, closed, open and focused menu states for D17-C09/C10, and two opacity endpoints for D17-C11. Browser tests own motion preferences, semantics, loading, progress announcements, eligible actions and focus. Test keyboard access and fast status changes directly in the browser. [Motion accessibility](https://motion.dev/docs/react-accessibility) · [Animate UI accessibility](https://animate-ui.com/docs/accessibility)
